# Hosting Provider

O usuário utiliza o **Firebase** (Firebase Hosting / App Hosting) como provedor de hospedagem para este projeto.

- **NÃO** mencione a Vercel para deploys, tempo de compilação ou processos de CI/CD deste projeto.
- Quando se referir à subida de código, tempo de propagação online ou hospedagem, direcione o contexto sempre para o ecossistema do **Firebase**.
